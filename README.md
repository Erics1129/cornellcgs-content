# cornellcgs.org content

The words and portraits shown on https://cornellcgs.org, edited at https://cornellcgs.org/admin/ and committed here.

- content.json — the published document (only the sections that differ from the site's built-in words)
- images/ — uploaded portraits, cropped square, named by content hash
- admin-key.json — the admin's GitHub connection, encrypted under the admin passcode

The admin overwrites this repo; edit by hand only if you know what you are doing.
